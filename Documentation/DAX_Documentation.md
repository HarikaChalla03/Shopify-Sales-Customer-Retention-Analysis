
# DAX Documentation

## Project
Shopify Sales & Customer Retention Analysis

This document explains the key DAX measures and calculated columns used in the Power BI report.

# Total Revenue
Total Revenue = SUM(shopify_sales[Revenue])
Explanation : Calculates the total sales revenue generated across all orders.
Business Use : Used to monitor overall business performance and compare revenue across products, locations, and customer segments.

# Total Orders
Total Orders = DISTINCTCOUNT(shopify_sales[Order Number])
Purpose : Counts the number of unique customer orders.

# Total Customers = DISTINCTCOUNT(shopify_sales[Customer ID])
Calculates the number of unique customers.

# Repeat Customers
Repeat Customers = 
CALCULATE(
    DISTINCTCOUNT(shopify_sales[Customer ID]),
    NOT(ISBLANK(shopify_sales[Second Purchase Date]))
)
Counts the number of customers who have placed more than one order.

# Average Order Value
Average Order Value = DIVIDE([Total Revenue], [Total Orders])
Purpose : Measures the average amount customers spend per order.
Business Value : Helps evaluate purchasing behavior and pricing strategies.

# Repeat Purchase Rate
Repeat Purchase Rate = DIVIDE([Returning Customers], [Total Customers])
Purpose : Calculates the percentage of customers who made more than one purchase.
Business Value : Measures customer loyalty and retention.

# Revenue per Customer 
Revenue per Customer = DIVIDE([Total Revenue],[Total Customers])
Calculates the average revenue generated by each customer.

# Estimated CLV
Estimated CLV = [Average Order Value] * [Purchase Frequency]
Estimates the average lifetime value of a customer using order value and purchase frequency.

# First Purchase Date 
First Purchase Date = CALCULATE( 
MIN(shopify_sales[Order Date]), 
ALLEXCEPT(shopify_sales,shopify_sales[Customer ID])
)
Finds the first purchase made by each customer.

# Second Purchase Date
Second Purchase Date = 
VAR CurrentCustomer = shopify_sales[Customer ID]
VAR CustomerOrders =
    SUMMARIZE(
        FILTER(
            ALL(shopify_sales),
            shopify_sales[Customer ID] = CurrentCustomer
        ),
        shopify_sales[Order Number],
        shopify_sales[Order Date]
    )
VAR SecondOrder =
    TOPN(
        2,
        CustomerOrders,
        shopify_sales[Order Date], ASC,
        shopify_sales[Order Number], ASC
    )
RETURN
    IF(
        COUNTROWS(CustomerOrders) >= 2,
        MAXX(SecondOrder, shopify_sales[Order Date]),
        BLANK()
    )
Identifies the date on which a customer made their second purchase.

# Days to Second Purchase
Days to Second Purchase = 
IF(
    ISBLANK(shopify_sales[Second Purchase Date]),
    BLANK(),
    DATEDIFF(
        shopify_sales[First Purchase Date],
        shopify_sales[Second Purchase Date],
        DAY
    )
)
Calculates the number of days between a customer's first and second purchase.


# Return Bucket
Return Bucket =
SWITCH(
TRUE(),
ISBLANK(shopify_sales[Days to Return]),"No Repeat Purchase",
shopify_sales[Days to Return]<=30,"Within 30 Days",
shopify_sales[Days to Return]<=60,"31-60 Days",
shopify_sales[Days to Return]<=90,"61-90 Days",
"90+ Days"
)
Groups customers based on the time taken to make a repeat purchase.


# Purchase Frequency  
Purchase Frequency = DIVIDE([Total Orders],[Total Customers])
Measures how frequently customers place orders on average.
